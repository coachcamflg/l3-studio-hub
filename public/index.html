Troubleshooting
Mic not picking up audio
  1. Click the light-up button on the RODECaster channel for that mic
  2. Switch from Condenser to Dynamic (or vice versa)
  3. Switch it back — this usually resolves the issue
  4. If still dead, check the XLR cable connection at both ends
  5. Try a different XLR cable from the equipment closet
Riverside showing 720p instead of 1080p
  1. Go to Riverside Settings → Recording
  2. Verify video quality is set to Highest available (4K option) — it outputs 1080p
  3. Check that the RODECaster Video is connected via the gray cable to Output 1
  4. If still 720p, disconnect and reconnect the gray cable
  5. Restart Riverside if the issue persists
Camera feed not showing in Riverside
  1. Confirm the Hollyland transmitter is powered on and paired to the camera
  2. Check that the camera is turned on and the lens cap is removed
  3. Verify the camera's HDMI output is set to 1080p
  4. Try unplugging and re-plugging the Hollyland transmitter
  5. If using 5+ cameras, check Input 5 adapter connection
Camera overheating
  • If recording 4K internally, switch cameras to output 1080p to reduce heat
  • Ensure fans are running on setting 2 and pointed at cameras
  • Check that cameras are plugged into white USB-C cables from power blocks
  • If a camera overheats mid-session, power it off for 2 minutes then restart
Stream Deck not working
  • Check USB connection to the MacBook Pro
  • If disconnected, open Riverside manually from the browser instead
  • Stream Deck shortcuts are convenience features — everything can be done manually
Studio TV or Producer TV not turning on
  1. Confirm the "Echo, turn on studio" voice command was recognized
  2. Stand directly in front of the TV and try the Roku remote manually
  3. Check that the TV is plugged into a powered outlet (controlled by Echo)
  4. If the outlet is dead, check other Echo-controlled outlets — may need to re-issue voice command
Where are extra power blocks / cables?
  • Extra power blocks: blue bin in the closet next to the kitchenette
  • USB-C to USB adapters are also in the blue bin
  • For recordings outside the studio, use floor plugs to power equipment
